# Registre des règles métier

Toute fonction métier commence ici, **avant le code** : la règle en français, sa source, son test.

Format d'une règle (`RM-AMZ-nnn`) :

| Champ | Contenu |
|---|---|
| Règle | Qui décide quoi, quand, sur quelle donnée ; ce qui n'est jamais deviné |
| Source | Texte officiel lu (lien, date de lecture) ou « non sourcé » |
| Statut | lu / non lu / à valider |
| Blocage | bloquant seulement si sourcé ; sinon avertissement |
| Test | Entrées, résultat attendu, cas limites ; nom du test qui cite `[RM-AMZ-nnn]` |

Registre : `registre.md` (à remplir, premier lot : marge et TVA, verdict, lots prévu/réel).
